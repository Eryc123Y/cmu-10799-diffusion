# Lecture Exercises

This folder contains lecture-specific exercise packs for CMU 10-799 Diffusion & Flow Matching.

Current packs:

- `lecture-4-score/`: post-Lecture-4 exercises connecting score-based model theory back to the HW1 DDPM implementation and forward to HW2 Flow Matching.

Build the Lecture 4 Typst handout with:

```sh
typst compile exercise/lecture-4-score/lecture4-score-exercises.typ
```

Handouts use the `typsidian` Typst Universe package. See `exercise/AGENTS.md` for the template and collaboration rules.
